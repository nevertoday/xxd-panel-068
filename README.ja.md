# 🦁 XXD Panel 068

### 東洋のフリーハンドの筆致の空白、インクの線、明るい色を使用して写真を再確認します。

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 068 は、ビジネスの立場、白と黒の計算、仮想と現実の相互作用、密度の集合と分散を利用しています。伝統的な中国絵画のテンプレートをコピーするのではなく、さまざまなストロークのインク ライン、抑制された明るい色、現代的な編集順序を使用して、主題のアイデンティティと後味を保持しています。

**キーワード:** 東洋の手描きの筆致 · 白を黒として使う · 墨線と淡い色 · タイトルとあとがきの組版 · 現代的な編集順序

## 使用する

```text
/xxd-panel-068 photo.jpg --mode design-only --size 3:4 --text prompt --locale ja-JP
```

単一画像、ディレクトリ バッチ、4 つの出力モード、複数のサイズ、および 3 つのテキスト モードをサポートします。完全な動作については、[SKILL.md](SKILL.md) を参照してください。
