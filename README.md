# 🦁 XXD Panel 068

### 以东方写意的留白、墨线与淡彩重新观看照片

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 068 借鉴经营位置、计白当黑、虚实相生与疏密聚散，用有提按变化的墨线、克制淡彩和现代编辑秩序保留主体身份与余韵，而不是复制传统国画模板。

**关键词：** 东方写意 · 计白当黑 · 墨线淡彩 · 题跋排版 · 现代编辑秩序

## 使用

```text
/xxd-panel-068 photo.jpg --mode design-only --size 3:4 --text prompt --locale zh-CN
```

支持单图、目录批量、四种输出模式、多尺寸与三种文字模式。完整行为见 [SKILL.md](SKILL.md)。
